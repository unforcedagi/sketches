why this is interesting — philosophy · technique · aesthetics

Philosophy — the forest is one walk. A line that only went one way is a biography. A line that also went the other way is a tree. Every fork here is a turn the walk did not take, taken anyway; the ink is the set of those counterfactuals, and the dark spine is the prefix they still share. Desire Paths, in this collection, lets a crowd wear a single road out of the ground. This inverts that: one agent, every road, none of them preferred. Nothing is following a trail. The trail is the memory of having been able to choose.

Technique — replace, don’t prefer. Reset plants one tip. It must lay a short trunk (TRUNK ticks) before it can fork. A fork does not keep a privileged parent: the tip ends, and two symmetric outgoing tips begin, both at g+1, headings a±δ. Ink weight 0.70g and split rate exp(−0.12g) therefore decay with actual depth, not with how often a path was assigned the child role. Copies do not read each other. No exclusion, no wear, no Vicsek alignment. A weak radial tropism keeps a single walk from knotting; a held mouse replaces that with lean. Tips die of age or of the edge; their ink does not. Reset warms 140 ticks so the first watch is a trunk-and-forks, not a hair.

Aesthetics — thickness is agreement, hair is otherwise. Only the shared prefix is generation 0, so only the trunk is extra-dark. After a fork both roads are the same generation and the same weight. Paper-ink is the default because this is a drawing, not a heatmap; gold is the darkfield reading. Hold X to colour by generation: that is now a depth map. The live count is tips, not histories — histories are the picture.

Honest weaknesses. Histories pass through each other. A soft cap (~850 live tips) stops new forks so a long run cannot crowd the paper into a disk; without it, the canopy wins and the spine — the agreement — disappears. The first split is a coin flip, not a reading of occupied space (DLA would stick; Desire Paths would follow wear). The otherwise is free, which is the thesis and the visual risk. Residual radial tropism still presses a single walk into one sector so it does not knot; that is composition, not a privileged child. I have not seen this in Chromium; the paper palette is a guess at print, not a proof of it.
